ENGINEERING

Camera crew leaves. Engineering remains.

When I am not solving day-to-day operational issues, I engineer resilient, secure, and scalable IT solutions. My focus is on eliminating manual toil through intelligent automation and robust application architecture.

Architecture & APIs

I design systems using feature-based architecture (Controllers/Services/Middleware). My backend services are built primarily on Node.js/Express and Next.js API Routes, implementing strict state-machine workflows to prevent invalid data states.

Databases & Security

I leverage PostgreSQL and Supabase with versioned migrations and Row Level Security (RLS) to enforce tenant-aware data access. Security is integrated at the code level, including JWT, expiring magic links, HttpOnly cookies, AES-256-GCM encryption, and Zod input sanitization.

Integrations & AI

I build event-driven webhook architectures integrating with enterprise ITSM/ERP systems. I augment applications with AI (Google Gemini 2.5) as a deterministic layer to handle intent recognition and semantic search, deflecting tier-1 support tickets and intelligently routing complex issues.
